🎮 Система управления компьютерным клубом с самооплатой
📋 Описание проекта
Система для автоматизации управления компьютерным клубом с поддержкой самостоятельной оплаты через QR-коды. Позволяет клиентам самостоятельно начинать и завершать сессии, оплачивая время использования компьютеров.

🚀 Основные возможности
Для клиентов:
Сканирование QR-кода для начала сессии

Автоматический расчет стоимости по времени

Самостоятельная оплата через интегрированные платежные системы

Просмотр истории сессий и платежей

Для администраторов:
Управление компьютерами (добавление, удаление, обслуживание)

Настройка тарифов по времени и типам компьютеров

Мониторинг активных сессий в реальном времени

Финансовая аналитика и отчетность

Управление клиентами и их балансами

🏗 Архитектура проекта
Доменная модель построена на принципах DDD (Domain-Driven Design):
AggregateRoot
Базовый класс для агрегатов с управлением доменными событиями

Поддержка версионирования для оптимистичной блокировки

Автоматический трекинг изменений через доменные события

Entity
Сущности с уникальными идентификаторами

Реализация равенства на основе ID

Поддержка иммутабельности где это необходимо

ValueObject
Объекты-значения без идентификатора

Сравнение по всем компонентам

Иммутабельные по дизайну

DomainEvent
События для коммуникации между bounded context'ами

Поддержка Event Sourcing паттерна

Автоматическое проставление временных меток

🛠 Технологический стек
Backend: .NET 8, ASP.NET Core, Entity Framework Core

Database: PostgreSQL

Authentication: JWT, Identity

Real-time: SignalR для мониторинга сессий

Caching: Redis для производительности

Monitoring: OpenTelemetry, Health Checks
